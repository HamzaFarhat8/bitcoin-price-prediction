# Bitcoin Price Prediction

This project uses Machine Learning techniques to analyze historical Bitcoin price data and predict future price trends. It demonstrates data preprocessing, visualization, and predictive modeling using Python.

---

## Features

* Data preprocessing and cleaning
* Exploratory Data Analysis (EDA)
* Visualization of Bitcoin price trends
* Machine Learning model for prediction
* Evaluation of model performance

---

## Tech Stack

* Python
* Pandas
* NumPy
* Matplotlib
* Scikit-learn



